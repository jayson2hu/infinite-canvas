# 产品原型设计说明

状态：用于确认产品流程的独立静态原型，不属于正式应用；未连接账号、支付、模型服务或云存储。原型路径为 `prototype/index.html`，可直接用浏览器打开。

## 设计方向

服务国内个人创作者与小团队，第一条工作流选择电商商品视觉：一份产品说明 → 一张画布 → 生成与迭代 → 导出。保留上游无限画布的工作方式，将模型配置和密钥管理从普通用户的创作流程移到运营后台。

沿用上游 `web/src/lib/canvas-theme.ts` 的浅色画布基调：画布 `#f4f2ed`、面板 `#fbfaf7`、正文 `#292524`、次要文字 `#78716c`、边界 `#d6d3ca`，用 `#386551` 表示完成和可用状态。非画布页面也保持一致。演示仅展示浅色，正式集成时必须使用现有主题 token，并补齐深色模式。

字体使用本机的「微软雅黑 / PingFang SC / Segoe UI」中文无衬线组合。字号 12/14/16/22/32；标题依靠字重和内容组织，不使用宣传性大字或无关装饰。正文与表格左对齐，数额右对齐。视觉重点是画布里的创作过程，积分与账户信息保持安静、随时可见。

```text
┌──────────┬──────────────────────────────────────────┐
│ 品牌     │ 项目名                         账户与积分 │
│          ├───────────────────────────┬──────────────┤
│ 创作空间 │ 产品说明 → 视觉构图 → 结果 │ 生成设置     │
│ 积分账户 │                           │ 参数与报价   │
│ 首版范围 │             画布          │ 任务状态     │
│          │                           │              │
│ 开源来源 ├───────────────────────────┴──────────────┤
│          │ 原型说明：交互演示，未连接真实服务         │
└──────────┴──────────────────────────────────────────┘
```

移动端改为顶部导航、画布与设置上下排列；小屏中的画布允许在明确边界内横向浏览，页面本身不应横向溢出。操作有键盘焦点和文本标签；模态框使用原生 dialog，支持 Escape 关闭。没有自动播放动画。

## 方案复核

没有另外做通用 SaaS 营销页：用户当前需要评估改造后的创作与计费过程。保留项目已有画布主题，避免设计成与现有代码难以整合的新品牌系统。仅在画布作品中使用构图色块，账户页面用交易明细解释费用。示例作品是 CSS 排版占位，不冒充 AI 实际生成结果。

## 可操作流程

- 切换创作空间、积分账户、首版范围。
- 修改生成模式、张数与提示词，实时显示示例报价。
- 提交演示任务后冻结积分，由演示控件分别完成成功结算或失败退回。
- 同一任务处理中不能重复提交；余额不足时引导查看积分账户。
- 打开邮箱注册演示，体验发送、验证和完成步骤；只使用演示验证码，不发送邮件，不收集密码，不创建真实账户。
- 查看交易流水；充值入口明确标为尚未接入，不制造真实付款成功状态。

演示积分和身份只保存在页面内存，刷新即重置；真实产品的余额、验证码和任务状态只能由服务端处理。
